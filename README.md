Para instalar localmente:
Para instalar en el entorno local, se adjunta el archivo proyecto.zip que contiene el software.
Recomendaciones:
- El archivo de la base de datos, se deja en la carpeta del proyecto para que hagan la
instalación su nombre es Basedatos.sql
- La versión usada de es PHP 7.4.22
- Para editar el archivo de conexión de la base de datos, está en la ubicación
Connections/ conexion.php.
- Para ensayar el cpanel se puede usar estos datos para iniciar sesión:
- Usuario: admin
- Clave: admin
-Usuario: empleado
-Clave: empleado
